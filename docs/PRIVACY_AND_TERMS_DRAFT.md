## 參考其他公司的做法

參考目的在於組織說明與拆分資料生命週期，沒有複製其條文或照搬保留年限。

- [LINE 台灣隱私權政策](https://terms.line.me/line_tw_privacy_policy?lang=zh-Hant)：按資料類別、蒐集用途及聯絡權利說明。我們採用相同的分類方式，但不加入 App 沒有的支付、通訊錄或廣告追蹤用途。
- [Discord 資料保留說明](https://support.discord.com/hc/en-us/articles/5431812448791-How-long-Discord-keeps-your-information)：區分服務資料、內容刪除、安全紀錄及備份。其備份期限為30至45天；這是 Discord 的作法，不能當成本專案或 Supabase 的保證。我們也不照搬它的刪帳冷靜期與安全紀錄年限。
- [Supabase 備份文件](https://supabase.com/docs/guides/platform/backups)：Free 專案應自行定期匯出，資料庫備份不等於 Storage 物件備份。因此本專案不宣稱已有可用的自動備份或固定期限內逐筆清除供應商備份。

## 隱私說明樣板

我們處理登入信箱、帳號識別碼與基本個人資料，以驗證登入及顯示參與者資訊。拼單、加入申請、成員、費用與分工確認，以及群組訊息，用於提供協調功能。偷揪分身設定、本人確認的需求與語義向量，用於找到符合條件的配對。檢舉、申訴及處置紀錄，用於處理爭議與維護服務。

一般使用者僅能依功能權限查看資料；不提供其他人的私人需求原文、檢舉者身分或管理者內部備註。授權管理者可查核被檢舉的內容及私密案件，權限受明確名單及到期時間限制。

帳號與功能資料存於目前指定的 Supabase 開發專案。Google 登入透過 Google 與 Supabase Auth 處理；App 不取得 Google 密碼。不宣稱資料一定存於台灣，正式政策須確認專案區域與供應商處理地點。

啟用本機 AI 時，訪談內容會傳到開發者管理的 Windows／Mac 後端，再交由該電腦的本機模型處理；**這不是全程留在手機的處理方式**。已確認需求可由本機向量模型產生向量，上傳 Supabase 供跨使用者搜尋。向量仍按私人資料保護。模型輸出只作建議，不代表當事人同意。目前不呼叫 OpenAI 或其他付費推論，不將使用者聊天當成模型訓練資料。

使用者可在 App 修改個人資訊、撤回需求、封鎖他人、檢舉與提出申訴，也可使用帳號刪除流程。查詢、更正或其他資料請求，內測先透過「幫助與回報」提出；正式公開前需提供可用的支援信箱及經確認的受理流程。

## 保留期限：先定義目標，不能寫成已執行

| 資料 | 目前實際行為 | 樣板政策目標（待團隊確認及實作） |
|---|---|---|
| 帳號、設定 | 保留至本人刪帳或另行處理 | 提供服務期間保留 |
| 過期／撤回需求 | 停止有效配對，原資料仍在；撤回／版本變更會移除向量 | 過期30天後清理，不自動動到成團歷史 |
| 需求向量 | 搜尋排除過期、撤回、版本或模型不一致的向量；版本變更同步失效 | 最遲隨原需求清理；不視為匿名資料 |
| 拼單、協調與訊息 | 依帳號刪除、處置及現有功能清理，尚無一般定時到期作業 | 結束90天後清理或去識別；須先處理多人歷史依賴 |
| 檢舉、申訴、處置紀錄 | 私人保存；原案件或帳號刪除會依既有外鍵連帶清理 | 結案180天後清理；保留例外及刪帳衝突須另行設計 |
| 開發者自管備份 | 尚未建立正式備份與輪替作業 | 30天輪替，還原時重新套用已刪除資料清單；尚未實作 |
| 供應商備份／日誌 | 依供應商機制，無逐筆清除證據 | 確認適用方案及合約後另行公告，不保證30天 |

目前帳號刪除會實際清理應用資料及登入工作階段，沒有 Discord 式的刪帳冷靜期。不能對外宣稱「刪帳後仍固定保留180天完整案件」；現有實作並非如此。也不能宣稱已能刪除所有備份，或用假信箱提供有效客服。

本輪沒有啟用排程、大量刪除資料、建立備份、寄信或購買服務。

## 使用規範樣板

1. 提供正確的需求與可配合條件，避免散布詐騙、騷擾、侵權或其他不當內容。不要在公開欄位或檢舉內容貼密碼、驗證碼及付款敏感資訊。
2. 平台協助媒合與協調，沒有代為付款或保證交易完成。金額、優惠券、取餐與供餐條件須由參與者確認；飲食與過敏資訊須向供餐者查證。
3. AI 可能理解錯誤。儲存前由本人核對；配對後由全員明確確認同一版費用與分工。修改方案會使舊同意失效。
4. 管理者查核後可取消被檢舉拼單或隱藏被檢舉訊息。隱藏保留原文供查核，非直接抹除證據。處置不會自動停權帳號。
5. 回報者與受到處置的內容作者可就同一事件提出一次申訴，查看自己的覆核結果。覆核結案是記錄，不會自動恢復拼單、名額或任何人的同意。
6. 尚未提供獨立覆核委員、完整停權與解禁、訊息恢復或被取消拼單的恢復工具；不得宣稱已有這些能力。
