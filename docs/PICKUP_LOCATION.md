# 取餐地點與個人常用地點

正式新增與主揪編輯拼單改用同一個 `LocationPicker`，不再要求手填經緯度。先選校園參考點、搜尋或主動定位，可開地圖點選／拖動圖釘，再填名稱與取餐說明，按「確認取餐地點」後才供發文使用。改名稱、說明或位置會要求重新確認；取消地圖選點保留原本已確認位置。

## 校園點

提供正門、麥側（依使用者的「麥測」理解為指南路側門）、商學院、莊九（莊敬九舍）、藝文中心、政大後門六個入口。前四個建築／校門參考點取自[政大官方校園導覽](https://bdmap.nccu.edu.tw/zh-tw/campus-mapbox?layout=0)的[公開座標資料](https://bdmap.nccu.edu.tw/zh-tw/Map/GetMapList/1)，2026-10-22 查核；資料中商學院、莊九及藝文中心是建築點，並非已驗證的實際領取入口。

麥側使用 OSM 路口節點 2316031257 作為地圖起始參考，後門使用 OSM 節點 1749424521 的校園入口道路參考（與校方[後門經恆光橋進入的說明](https://osa.nccu.edu.tw/tw/住宿輔導組/最新消息/14307-115學年新住宿生進住宿舍注意事項)交叉核對）。這兩個捷徑必須在地圖再次點選實際取餐點後才能確認，避免把路口或道路參考點誤當成精確領取位置。程式不查詢校園來源或 OSM 資料 API 來自動回填；常用點直接隨 App 提供。

## 免費地圖與導航

- Leaflet 1.9.4 JS／CSS 隨 App 打包，保留 BSD 授權檔。可用 `node scripts/update-leaflet-assets.mjs` 從鎖定套件重新產生資產；無遠端 CDN 程式。
- Web 使用有 sandbox 的 iframe；iOS／Android 使用 Expo SDK 57 對應的 WebView 13.16.1。訊息橋接核對來源視窗、通道及有限座標，不把使用者文字插進 HTML。
- 圖磚預設使用 OpenStreetMap 標準 HTTPS 服務，保留可見來源標示、瀏覽器 Referer、原生 App User-Agent 及預設 HTTP 快取，不預抓區域或離線下載。`EXPO_PUBLIC_MAP_TILE_URL` 可改為其他 HTTPS OSM 相容供應來源，需自行核對新供應商授權。
- 公共服務是有限資源、無可用性保證，需遵守 [OSM 圖磚政策](https://operations.osmfoundation.org/policies/tiles/)。地點搜尋沿用 Photon 的明確點擊、快取、節流及失敗備援；不是每次拖動就反查地址。
- Google Maps 跳轉使用官方 URL `maps/dir/?api=1&destination=緯度,經度&travelmode=walking`，不需要 API key。起點由 Google Maps 在使用者操作時決定，App 不附帶本人即時座標。

## 儲存方式

取餐名稱與經緯度沿用既有後端欄位；地址加上換行與「取餐說明：」標記保存補充說明，合計最多 500 字，無共享資料庫 migration。舊紀錄空值與只有地址的紀錄仍可載入。貼文顯示地址及取餐說明，導航只採用實際儲存座標。

自訂地圖點或目前定位在確認後詢問是否「加入我的常用地點」，不自動保存；拒絕仍可發文。這是本裝置、依登入帳號隔離的個人名單，不修改全校共用點、不提供跨裝置同步。最多 20 個，五公尺內位置避免重複；可移除。

Web 使用 localStorage；原生使用 SecureStore，每筆地點分開保存以限制單筆大小。儲存失敗不宣稱成功，不影響已確認的發文座標。App 未授權定位時仍可用常用點、搜尋或地圖選點；地圖底圖請求會向供應商透露目前查看的區域。

## 驗證與接續

新增單元／元件測試涵蓋校園點、手動確認、補充說明、舊資料空值、搜尋、定位、Google Maps 目的地、自訂點詢問／拒絕、帳號隔離、保存重載與名單上限。瀏覽器以本機替代圖磚驗證真正 Leaflet 點選、拖動、iframe 傳遞及移動視角不選點，未向公共服務發出自動化圖磚請求。

本輪完整前端 53 組／240 項測試、TypeScript 與變更檔 ESLint 通過。瀏覽器合成互動證據在 App 忽略目錄 `.local/pickup-qa/interaction.json`；示意底圖不是實際校園圖資或實地驗收。

Expo Go 可重新載入測試；既有自訂原生 build 因新增 WebView 依賴，需在 Mac／對應原生環境重新建置。尚須以真實手機驗證觸控、定位權限、常用點跨重開保存，以及校園實地領取位置；編譯與合成地圖互動驗證不代表實地導航驗收。
